# Prieseity — portfolio

Static portfolio site (HTML/CSS/vanilla JS). All content lives in `site/assets/js/data.js`.

## Run locally

```bash
node serve.js
```

Then open http://localhost:5173.

## Structure

- `site/` — the website (pages, `assets/css`, `assets/js`, images, videos)
- `serve.js` — tiny zero-dependency static server with video range support
